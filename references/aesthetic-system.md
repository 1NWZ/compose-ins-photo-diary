# 审美系统

## 1. 从整组照片出发

逐张看图，建立简短分析记录：图 ID、主体、主色与明度、情绪、焦点 `(fx, fy)`、需要完整保留的区域 `(left, top, right, bottom)`、方向敏感性、可见事实。坐标均相对于 EXIF 校正后的图像，归一化到 0–1。

再判断全组是否存在共同事件、时间或地点的证据，区分「用户明确说明」「图片可见」「尚不确定」。同样的树木、咖啡杯或色调不足以证明共同旅行。不要通过人物外貌推测身份或关系。

## 2. 模式选择

| 模式 | 素材关系 | 文案 | 字体与组织方式 |
|---|---|---|---|
| `bold-index` | 题材较杂、颜色跳跃、事件感强 | 基于可见内容的栏目词，如 `food`、`objects`、`outside` | Archivo Black；3–4 个有节奏的栏目行，照片插入词语之间或之后 |
| `quiet-journal` | 色彩和情绪高度统一，自然、静物、独处氛围明显 | 克制短句，如 `small pauses`、`stillness`；`soft rain` 只在确有雨景时使用 | Cormorant Garamond；中央紧凑小簇，外围大面积安静留白 |
| `place-note` | 同一次出行、同一地点或同段旅程有可信证据 | 标题、连接词和可信地名组成视觉句子 | Inter Light（weight 300）；照片作为名词插进句子，阅读顺序清晰 |

默认依次判断 `place-note` → `quiet-journal` → `bold-index`，不是平均随机。模式边界模糊时，选择最合理的两个，用同一背景、同一套原图各做低分辨率预览。不要为完成比较而改写事实。

用户点名一种模式时尽量按指定模式执行。即使指定 `place-note`，没有可靠地名时也只能使用 `a walk`、`along the way` 等非特指表达，不能把互不相关的素材说成同一趟旅行。

## 3. 构图与文字

- 照片是生活片段，不是铺满画面的墙。建议照片加文字占画布 20–45%，至少留下 35% 没有前景元素的面积。脚本仅验证面积，背景是否安静仍需视觉判断。
- 各图不必同尺寸。用一到两张较醒目的图片建立视觉重心，其余形成节奏。避免小到看不清；本实现照片短边至少 120 px。
- 安全边距 64 px。正文通常 28–60 px，主要栏目词可用 72–140 px。文字过长时改短句、换行或调整布局，避免缩成不可读的小字。
- 文字以英文为默认，控制总词数。不得把虚构日期、温度、经纬度、航班号或亲密关系当装饰。用户要中文时需另配覆盖中文字符且许可明确的字体并扩展渲染器；当前三种内置字体与脚本使用可打印 ASCII 英文。
- 使用 `()` 或 `[]` 给一个词或一小组照片分组，通常 1–3 对。它们必须有注释、分组或阅读提示功能，不要成为每张照片的外框。
- 默认不重叠照片，也不让文字压到照片上。图片里的人脸、手、文字和关键物件应落在保护框内，裁切必须完整包含该区域。

## 4. 背景生成隔离

背景生成只能接收纯文字摘要，不能接收用户照片、源图路径、源图 URL、身份描述或最近图片引用。生成两张独立候选；如果工具单次只能返回一张，调用两次。背景应为不透明的竖版位图，优先 3:4。

提示词由「综合色系 + 情绪 + 抽象环境/材质 + 主要留白区域 + 排除项」构成。例如：

> A vertical 3:4 editorial background only. Muted warm ivory and pale sage, subdued daylight, subtle natural paper texture, quiet atmospheric color transitions. Keep the central 70 percent visually calm for later photo and type placement. No photographs, no people, no faces, no recognizable landmarks, no objects competing for attention, no frames, no collage, no lettering, no words, no symbols, no logos, no watermark.

这是结构示例，不是每次照抄的固定提示。背景可以有轻微的抽象环境感，但不能借此补充未经证实的真实地点。不要让生图模型生成文字、占位照片或最终排版。

## 5. 候选评分与停止条件

对两张背景分别用 0–5 分评价：色彩协调、情绪契合、留白可用性、文字可读性、画面克制度；总分 25。分数是 Agent 的审美判断，不是脚本或模型自动测量结果。

出现人脸、伪造生活照、标志、文字、水印、相框或明显主体竞争时直接判为不合格，不靠总分掩盖。两张都不合格时，可针对失败原因再生成一轮；两轮仍无合格背景则说明原因，停止正式交付。

将结果保存在工作目录 `direction.json`，至少包含：

```json
{
  "mode": "quiet-journal",
  "mode_reason": "三张静物的颜色和情绪一致，没有共同地点证据",
  "facts": [],
  "candidates": [
    {"path": "background-a.png", "prompt": "完整实际提示词", "tool_record": "宿主提供的实际生成记录（如有）", "scores": [4, 5, 5, 4, 5], "eligible": true},
    {"path": "background-b.png", "prompt": "完整实际提示词", "tool_record": "宿主提供的实际生成记录（如有）", "scores": [4, 4, 3, 4, 4], "eligible": true}
  ],
  "selected": "background-a.png",
  "reason": "中央留白完整，低对比纹理能承接细衬线文字"
}
```

没有工具生成记录时用 `null`，不得编造调用 ID。评分数组依次对应上面的五个维度。

## 6. 最终视觉检查

先看缩略图：留白、重心、阅读顺序、照片节奏是否成立；再看 100%：脸和物件是否保全、文字是否清晰、边缘是否干净、是否有意外重叠。检查照片数与清单一致，确认背景未抢走主体。

如果比较两个模式，可同样按 0–5 分评价素材关系表达、层级、留白、裁切和可读性，保留更好的一版并记录理由。机器校验通过不等于审美通过。
